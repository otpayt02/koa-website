## Recommended website information architecture

1. **Updates** — a dated, searchable stream for Facebook-derived announcements, event recaps, leadership updates, and opportunities. Each item carries date, source, status (`current`, `past`, `archived`), and a call to action only while verified.
2. **Advocacy** — stable explanation plus one current, dated update card. The Washington trip is an archive/news item, not a substitute for current policy guidance.
3. **People / leadership** — board-approved bios and role photos; keep personal narratives to the detail each person approved.
4. **Programs / community** — no inferred program pages from reposted graphics. Create sections only when KOAmerica confirms ownership, service scope, schedule, and contact path.
5. **Media library** — intentional collections with captions, event/date, rights status, credit if needed, and a text alternative per image.

## Per-image accessibility and search record

Before a photo enters the website, create one record in `KOA-content-photo-approval-intake.docx` with:

- literal alt text that describes the visible image and context; empty alt only for decoration;
- optional visible caption and credit;
- page role, event/date, rights/approval owner, and source URL;
- crop/focal point/text-safe side plus allowed corrections;
- a source-backed entity/context statement for image search and AI answers.

Use the organization name **Karen Organization of America (KOAmerica)** in surrounding headings, titles, and page copy. Where appropriate and approved, state plainly that KOAmerica is a Karen community nonprofit and **not KOA Campgrounds or the Shepherdsville/Louisville South campground**. Do not force this phrase into image alt text or unrelated pages.
