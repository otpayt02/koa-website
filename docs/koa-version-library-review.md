## Base I would build toward deployment

Start from the **current canonical React application** at `app/[lang]/page.tsx` → `components/CinematicLanding.tsx`, then isolate its intended changes into a clean release branch. It already owns the multilingual routes, accessible navigation, authentic seal, program destinations, and draft-based home content. Use the static HTML and historical branches as references. Do not deploy a built `dist` copy or make the URL clone the new source of truth.

Phase 0, which can be completed locally: make a page-by-page content map from the owner-supplied `content/koa-website-content-draft.md` (a Word-format file despite its `.md` name). For every visible claim or action, mark **owner source / reviewed evidence / proposed addition / planned**. Then align the home, About, Programs, Advocacy, Donate, and Contact journeys before tuning motion. A deployment candidate needs browser evidence at desktop, narrow mobile, and reduced motion, a successful production build, functional route/action checks, and owner approval for content and publication.

## Content and delivery gaps to resolve

1. **The supplied page map and the app diverge.** The draft names Home, About, Programs, Advocacy, Donate, and Contact as primary journeys. The React app has About, Services, Collaborate, Dictionary, AI, Music, and other routes, but no dedicated Advocacy or Donate route. Decide where advocacy and giving live in the top navigation; label Programs consistently rather than forcing visitors to decode “Services.”
2. **The first screen needs a practical path.** The current film states the organization and later offers “Get involved” and “Contribute language.” The draft's visitor paths are “Support our work” and “Get involved.” Until giving is approved, keep a clear, honest non-payment support/contact path beside Programs. Put the three pillars—resettlement, civic engagement, cultural preservation—within one short scroll of the opening statement.
3. **Program cards need facts a visitor can use.** Name location or reach, who qualifies, current availability, what happens after a request, and a real contact/action for each. The current pages describe broad possibilities; the owner draft still has placeholders for service specifics, Karen New Year, and the National Youth Advocacy Program's actual elements. Distinguish KOA-delivered programs from referrals or future plans.
4. **Advocacy needs dated evidence and a clear ask.** The owner draft contains a BRAVE Burma Act status and proposed next steps that may change. Verify the bill status against an official source on publication day; identify what KOA has actually done, then give the visitor one concrete action. Do not make old bill milestones look current by leaving them undated.
5. **Donation wording is ahead of verification.** The React Collaborate page contains a donation form and promises a receipt and tax-deductibility confirmation. The owner draft still asks for a processor, recipient, tax/EIN language, and mailing details. Disable or clearly stage any payment path until those are confirmed, and do not promise a receipt or tax treatment without an operating workflow.
6. **Contact claims need an operator behind them.** The app presents `hello@koamerica.org`, a three-business-day response claim, and a contact form. The draft still asks which inbox handles each inquiry and which channels are current. Verify mailbox ownership, form delivery, routing, privacy handling, and response capacity; provide a useful fallback if the form fails.
7. **People, photographs, and translations need provenance.** The draft has placeholders for leadership bios and founding milestones. Some current pages use generated imagery with human-gathering alt text. Confirm names, roles, subject consent, photo rights, and the status of each translated passage; label conceptual imagery where retained. Do not imply an AI image documents a real gathering.
8. **About needs the actual organization story.** Add an approved mission/charter statement, founding date and milestones, leadership/governance, geographic scope, and evidence of work. The current visual story can carry this, but the missing facts cannot be supplied by animation.

## Recommended page order

Home: identity and plain mission → immediate Programs / Get involved choice → three pillars with one real example each → dated advocacy and youth work → authentic community story → contact/support path. About: mission, history, people, governance. Programs: current services, availability, next step. Advocacy: dated issue brief, KOA action, visitor action. Donate: only after the payment/tax gate is satisfied. Contact: verified channels and routing. Preserve readable text and the same choices when motion is off.

## Evidence limits

This is a source and content audit, not a claim that all 40 distinct HTML files or 19 historical React refs were rendered successfully. The dashboard inventories and opens files that currently exist. Some built HTML exports may refer to missing historical assets; some older React refs may need dependencies or contain broken imports. Browser-visible comparison at normalized viewports is still required before picking a visual winner. StyleSeed's full score is unavailable because this repo has no `STYLESEED.md` or `.styleseed` registry; the UX recommendations use its audit criteria without asserting a passing score.
