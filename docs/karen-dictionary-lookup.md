# English to S'gaw Karen lookup

The full public-site translation queue is in `content/translation-queue.generated.json`: 1,668 text candidates and 2,346 context-specific word-area pairs. Those are review items, not approved translations.

`karendictionary.com` did not resolve on 2026-11-15. `https://www.karendictionary.org/` has an English-to-Karen search. Browser lookups returned **community** (6 main results), **advocacy** (2), **education** (7), and **vote** (5). Results include multiple senses, parts of speech, and scripts. A reviewer must select a S'gaw Karen sense in the context of the specific KOA sentence; the first result is not automatically correct.

The site's [Terms of Service](https://www.karendictionary.org/terms-of-service) assert rights in its text and prohibit copying without permission. Use the live dictionary as an individual reference and record its URL and reviewer decision. Do not bulk copy its dataset into this repository or feed it into model training. For a bulk lookup source, use a dataset with verified redistribution rights and retain its license, provenance, dialect, and sense data. Human approval remains required before publishing any S'gaw Karen proposal.
