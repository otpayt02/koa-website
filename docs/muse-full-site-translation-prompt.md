## Import behavior

`npm.cmd run translation:queue` creates source candidates; `npm.cmd run translation:check` catches a stale queue. Muse JSONL is imported with `npm.cmd run translation:import -- <jsonl-file> <review-output.json>`. The importer stores segment proposals, contextual word alignments, and target-language word segments in a review file. It does not change the live site or the model training database.

Karen Dictionary advertises English↔Karen lookup and publishes multiple datasets, including S’gaw and Pwo sources. Check the exact source and its terms for each lookup. Its website states “All Rights Reserved”; this prompt does not authorize bulk dataset copying. See [Karen Dictionary](https://www.karendictionary.org/) and its [dataset history](https://www.karendictionary.org/dataset-version).
