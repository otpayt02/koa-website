## Intake rule

For each new Facebook or Signal candidate, save the public post URL or approved private source reference, post date, original caption, local original filename, photographer or owner when known, consent status, faces-preserved status, and proposed site destination. Keep the untouched original beside any crop or enhancement. The website uses a derivative only when a side-by-side review confirms every face remains the original face.
