# How do we connect signal?

Signal is not one of your connected tools — your available connectors are Gmail/Calendar, GitHub, and Google Drive only. But Signal can absolutely be connected to your company brain as an external layer. Here's how it works and what you need to do.

## The Short Answer

Signal has **no official public business API** (unlike Gmail or Slack). To connect it to your KOA operating system, you need to run a **Signal bot number** through `signal-cli` (a third-party REST API wrapper), then bridge that into your AI workspace via an **MCP server**. Your executives would get KOA brain updates and decisions in a Signal group, and agents could post to Signal on behalf of the organization.

## What You Need (Step by Step)

### 1. Get a Dedicated Phone Number

Signal requires a phone number per account. Get a separate number (not your personal one) to serve as the **KOA bot account**. All 5 executives can be added to a Signal group with this bot.

### 2. Run signal-cli-rest-api

This is the open-source REST wrapper that lets software talk to Signal. The common setup is Docker:

```bash
docker run -d --name signal-cli-api \
  -p 8080:8080 \
  -v $HOME/.local/share/signal-api:/home/.local/share/signal-cli \
  -e 'MODE=json-rpc' \
  docker.io/bbernhard/signal-cli-rest-api:latest-dev
```

Then open `http://localhost:8080/v1/qrcodelink?device_name=koa-bot` and scan the QR code with the Signal app on the bot number's phone to link it.

### 3. Add an MCP Bridge to Your OS

Since your AI workspace is where the executives live, connect Signal through MCP so agents can read and send messages. Based on what I found, there are two practical paths:

**Option A: signal-mcp (for Claude Code)**

```bash
claude mcp add signal-mcp \
  -e SIGNAL_API_URL=http://localhost:8093 \
  -e SIGNAL_BOT_NUMBER=+15551234567 \
  -e SIGNAL_CHANNEL_TYPE=group \
  -e SIGNAL_CHANNEL_ID=<your-signal-group-id> \
  -- signal-mcp
```

**Option B: Nurture Signal MCP** (simpler, hosted)

- Go to `https://signal.gonurture.com/mcp`
- Copy the server URL
- Add it as a custom connector in your AI client (Claude, ChatGPT, or Gemini)
- Sign in and approve access — no API key needed


### 4. Create the KOA Executive Signal Group

- Add all 5 executives to one Signal group
- Add the KOA bot number to the group
- This becomes the channel where the brain speaks: agents post decisions, meeting reminders, and approval requests; executives reply and the OS logs it back to the brain

## Field Reference

| Field | Purpose | Example |
| :-- | :-- | :-- |
| `id` | Unique identifier | `sgaw-0001` |
| `en` | English source text | `"Welcome to..."` |
| `sgaw` | S'gaw Karen translation | `"ကyw"` or `""` if empty |
| `context` | Where it's used | `homepage`, `footer`, `navigation`, `about` |
| `section` | Specific page section | `hero`, `contact`, `nav`, `mission` |
| `status` | Translation workflow state | `draft`, `empty`, `verified`, `blocked` |
| `verified` | Human review sign-off | `true` / `false` |
| `reviewer` | Who verified it | Name or null |
| `notes` | Flags for the agent | `"Needs S'gaw Karen translation"` |
| `created_at` | When the entry was added | ISO timestamp |
