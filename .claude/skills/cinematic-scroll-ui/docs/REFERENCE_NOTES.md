# Creative Reference Notes

These references inform principles, not copied code, assets, text, or branding.

## Juan Mora

Reference: https://juanmora.co/

Useful principles:

- oversized typography with strong editorial hierarchy;
- long-page rhythm that rewards continued scrolling;
- polished micro-interactions supporting portfolio navigation;
- clear service content underneath expressive direction.

## Trionn

Reference: https://trionn.com/

Useful principles:

- motion-led transitions between substantial content blocks;
- confident typography paired with structured, credible information;
- project navigation that remains clear despite expressive visuals;
- restrained repetition and deliberate visual pacing.

## Kononenko architectural experience

Reference: https://knko.pro/

Useful principles identified in public project descriptions:

- blueprint and drawing-style reveals;
- ink-like hover transitions;
- circular motion used as an accent rather than a hard container;
- smooth project interactions with minimal layouts and generous space.

## Adaptation rule

Translate every observed pattern into the current organization’s identity, content, accessibility needs, and performance budget. Do not reproduce proprietary layouts, source code, copy, imagery, or exact interaction sequences.
