# KOA prompt packs

Copy a prompt below into your approved AI tool and fill in the brackets. A human executive reviews every output before publication or filing. Use approved, non-sensitive source material only; `inbox/new/` is not an access-controlled workspace.

## Bilingual flyer or video

```text
Create a KOA [flyer/video script] for [event] on [date, time, location]. Use only these approved facts: [paste]. Audience: [audience]. Languages: English and [language]. Mark every translation as DRAFT FOR HUMAN REVIEW. Do not invent contact details, attendance numbers, photos, quotes, or promises. Deliver: English copy, translated draft, visual sequence, accessibility text, and a fact-check list tied to the supplied facts.
```

## Translation review

```text
Compare the source text [paste] with this draft translation [paste] in [language]. Flag omitted, added, or ambiguous meaning and culturally sensitive phrasing. Preserve names and dates exactly. Return a table with source segment, draft segment, concern, and suggested revision. Mark uncertain terms for a qualified human reviewer; do not present the translation as approved.
```

## Decision logging

```text
Turn these approved meeting notes [paste] into a decision record. Include decision, date, participants as supplied, rationale, owner, next action, deadline, and source reference. Mark missing fields UNKNOWN. Separate decided items from proposals and open questions. Do not infer consensus or invent quotations.
```

## S'gaw Karen content review

```text
Review this proposed S'gaw Karen content [paste] against the approved source text [paste]. Identify meaning, spelling, register, and community-context questions for a qualified S'gaw Karen reviewer. Keep the original wording visible beside each suggestion. Do not publish, overwrite an approved translation, or claim native-speaker validation.
```
